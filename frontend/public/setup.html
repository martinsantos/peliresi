Setup restringido

El asistente de instalacion no se publica en ambientes productivos.

Las tareas de despliegue, credenciales iniciales, comandos SSH y verificacion operativa deben ejecutarse desde la estacion tecnica autorizada y mediante los runbooks internos del repositorio.

Para capacitacion y uso funcional, abrir /manual/. Para operaciones de servidor, usar el canal interno de DevOps.
