## Lo que no cambió / límites

No backend de producto, permisos/sesiones, base/esquema/numeración de producción, manual, login azul, marca ni paleta institucional. No publicación, migración, instalación de dependencias, Docker nuevo, automatización, agentes ni envíos de correo/push/mensajes. QA se cerró por identidad de PID/directorio; puertos 3037/4177/55440 cerrados y datos conservados.

El backend para QA se compiló sólo como runtime, reutilizando tipos compartidos y sin emitir declaraciones. La instalación compartida de producción no incluye todos los tipos de desarrollo y la emisión de declaraciones con tipos externos falla por portabilidad. No certificar con ello un build backend estándar ni una nueva suite backend.

No certifica UI global, teléfonos físicos, Safari, PWA instalada, batería, ruido/transcripción, PDF legal ni 100%. Tampoco prueba entrega externa: los proveedores permanecieron deshabilitados. El título del header app puede abreviarse a 360 px; el título completo queda visible en el contenido.

Siguiente revisión acotada: tablas/hover/teclado y reportes, avisos generales sin expediente asociado, y etiqueta de actor «En línea» que no equivale a presencia conectada. Mantener los deltas backend experimentales separados; no reactivar el mega-test automático.
